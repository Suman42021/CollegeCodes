## 📝 Included C Programs

Here is a breakdown of the practical codes currently in this repository and the core logic they demonstrate:

| File Name | Description | Core Concept / Logic Used |
| :--- | :--- | :--- |
| `Calc Avg of 3 nos.c` | Calculates the average of three input numbers. | Arithmetic operators (`+`, `/`) |
| `Check_Divisibleby_5_AND_3.c` | Checks if a number is divisible by both 5 and 3. | Modulo (`%`) and Logical AND (`&&`) |
| `Check_divisibleby_3_OR_5.c` | Checks if a number is divisible by either 3 or 5. | Modulo (`%`) and Logical OR (`||`) |
| `Max_among_3.c` | Finds the largest value among three inputs. | Relational operators and `if-else` conditions |
| `SwapUsing3rdVariable.c` | Swaps the values of two variables. | Assignment using a temporary third variable |
| `SwapWithoutUsing3rdVariable.c` | Swaps two variables without allocating extra memory. | Arithmetic operations (`+`, `-` or `*`, `/`) |
| `check_odd_even.c` | Evaluates if a given number is odd or even. | Modulo operator (`% 2 == 0`) |
